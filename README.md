# TFM-Ecology-Pipeline
Automated morphometric extraction (Python) and ecological statistical modelling (R) pipeline developed to analyze thermal lags and phenotypic variation in Lepidoptera across altitudinal gradients.

> Este repositorio actúa como un **portfolio técnico** para demostrar mis habilidades en programación (R/Python) y mi flujo de trabajo de *Open Science*. Contiene una muestra representativa de los algoritmos automatizados y modelos estadísticos creados para mi Trabajo de Fin de Máster. Los conjuntos de datos reales y los resultados ecológicos finales **se mantienen bajo embargo temporal** y no están incluidos aquí, ya que el manuscrito se encuentra en preparación para su publicación científica.
